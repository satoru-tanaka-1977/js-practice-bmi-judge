# js-practice-bmi-judge

JavaScriptの学習の一環としてコツコツ作成している、BMI（体格指数）の算出と自動判定を行うシミュレーションアプリです。

## 概要
身長と体重を入力することでBMI値を計算し、その結果に応じて「低体重」「標準」「肥満」などの判定メッセージを自動で切り替えて表示するツールです。

## 学習のポイント・こだわり
- **1日1行からの丁寧な積み上げ**: コードの意味や英単語の構造を一つひとつ理解しながら、手打ちで実装を進めています。
- **条件分岐（`if`文）の習得**: 前回の基本の型（入力・処理・出力）に加えて、プログラムに数値を判断させて結果を変える「条件分岐」の仕組みを新しく学んでいます。
- **論理構造の意識**: アプリの目的やデータが流れる順序を意識しながら、基礎からしっかりと組み立てています。
